# StarLoom Observatory

A fully responsive, multi-page business website for a fictional stargazing and astronomy company, built with HTML5, CSS3 and vanilla JavaScript.

**Live demo (GitHub Pages):** https://areej244.github.io/starloom-observatory/

**Live demo (Vercel):** https://starloom-observatory.vercel.app/

## Pages
- Home
- About
- Services
- Portfolio
- Contact

## JavaScript Features
- Responsive navigation menu
- Dark mode (saved in the browser)
- Typing animation
- Animated counters
- Image slider with arrows, dots and auto-play
- FAQ accordion
- Contact form validation
- Scroll-to-top button
- Animated starfield background (white stars on blue, blue stars on white)

## Technologies
- HTML5
- CSS3 (Flexbox, Grid, CSS variables, media queries)
- JavaScript (Vanilla)

1. Download or clone this repository.
2. Open `index.html` in any web browser.

No installation or build step is needed.
